# Neeraj Salve — Portfolio

A responsive personal portfolio built with Next.js App Router, TypeScript, Tailwind CSS, and ESLint.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Use `npm run lint` and `npm run typecheck` to check the project.

## Personalize

- Update social and email links in `src/app/page.tsx` and `src/components/site-header.tsx`.
- Put your resume at `public/resume.pdf` for the Download Resume button.
- Replace the sample project cards, skills, and experience with your own details in `src/app/page.tsx`.
- The theme button follows the device preference initially and remembers the visitor’s choice.
